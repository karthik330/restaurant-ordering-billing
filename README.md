# restaurant-ordering-billing

A simple restaurant ordering and billing web app.

## Run locally

Requires a modern web browser and a local static server.

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Try it

1. Set quantity to enable **Place Order** , upon clicking it will open the bill.
2. Check the selected items and total, then select **Pay Now**.
